*This guide covers installation.*

## Install via Package Manager

1. Open **Window → Package Manager**.
2. Find the *Essential Systems* package.
3. Import it.

## Import a system

1. Open **Tools → ES → Welcome Screen**.
2. Navigate to the **Systems** tab.
3. Find a system you like and import it using the buttons.
