*This pack contains a collection of essential utility systems that aims to speed up your workflow.*

## List of utility systems

| System | What it does | Documentation |
|---|---|---|
| **Attributes** | `Optional` and `ShowIf` inspector attributes | [DOCS](./attributes) |
| **Singletons** | `Singleton`, `SingleSingleton`, and `SingletonScriptableObject` base classes | [DOCS](./singletons) |
| **Counter** | A simple timer you can step, check, and reset | [DOCS](./counter) |
| **Event Manager** | Subscribe, unsubscribe, and trigger events by name | [DOCS](./event-manager) |
| **Observables** | Observe objects or properties for changes | [DOCS](./observables) |
| **UI Manager** | Base class for showing and hiding UI panels | [DOCS](./ui-manager) |
