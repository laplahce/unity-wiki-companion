*Learn to use the included event manager.*

## Setup

Add the `Event Manager` script to any object in the scene.

## Usage

```csharp
public class Test : MonoBehaviour
{
    private void OnEnable()
    {
        EventManager.Subscribe("someevent", OnEvent);
    }

    private void OnDisable()
    {
        EventManager.Unsubscribe("someevent", OnEvent);
    }

    private void OnEvent()
    {
        Debug.Log("Event was called");
    }

    private void Start()
    {
        EventManager.Trigger("someevent");
    }
}
```

> Always unsubscribe in `OnDisable()` to avoid leaks.
