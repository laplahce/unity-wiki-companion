*Learn to use the included proximities.*

## Overview

The system has two parts:

- `Proximity Trigger` - attach to any object (e.g. the player). Triggers any `AProximity` it gets close to.
- `AProximity` - extend this to define what happens when the trigger enters or leaves the area.

## Custom proximity

```csharp
public class ChangeColorProximity : AProximity
{
    public Material inProximity, outOfProximity;
    public MeshRenderer meshRenderer;

    public override void Entered()
    {
        meshRenderer.material = inProximity;
    }

    public override void Left()
    {
        meshRenderer.material = outOfProximity;
    }
}
```

Both `Entered()` and `Left()` must be overridden.
