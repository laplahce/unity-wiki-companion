*This guide covers installation & render pipeline upgrades.*

## Install via Package Manager

1. Open **Window → Package Manager**.
2. Find the *Voxel Character Pack* package.
3. Import it.

## Upgrade to your Render Pipeline

1. Open **Tools → VCP → Welcome Screen**.
2. In the **Setup** tab, click the **Upgrade** button for your Render Pipeline & import it.
