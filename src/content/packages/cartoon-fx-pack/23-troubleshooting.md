*Solutions to frequently reported Cartoon FX Pack problems.*

## Common issues

If you cannot find a solution to your problem here, then be sure to [contact support here](/contact).

### I can't edit the properties

In some versions, when a Visual Effect component is a child of a prefab, some properties can't be edited. **To fix this**: `[RMB]` the parent game object and press **Prefab → Unpack**.

### Smoke particles aren't showing in 2D

Fix this by following the 2D guide in [the installation tab](./installation).
