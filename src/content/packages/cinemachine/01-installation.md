## Requirements

Make sure your project meets the minimum Unity version listed in the overview infobox before installing Cinemachine.

## Install via Package Manager

1. Open **Window → Package Manager**.
2. Import the Cinemachine package.
3. Wait for Unity to recompile and check the Console.

## Updating

Remove the existing Cinemachine folder before re-importing a new version to avoid stale files.
