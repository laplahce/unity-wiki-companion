**Odin Inspector and Serializer** (commonly *Odin*) is a commercial editor extension for the Unity engine developed by Sirenix. It enriches Unity's default inspector with a large set of attributes for laying out, validating, and grouping serialized fields, and ships an independent serialization layer capable of persisting types that Unity's built-in serializer cannot.
