## Requirements

Make sure your project meets the minimum Unity version listed in the overview infobox before installing Odin Inspector and Serializer.

## Install via Package Manager

1. Open **Window → Package Manager**.
2. Import the Odin Inspector and Serializer package.
3. Wait for Unity to recompile and check the Console.

## Updating

Remove the existing Odin Inspector and Serializer folder before re-importing a new version to avoid stale files.
