*Quick-reference for which versions, render pipelines & platforms the pack is compatible with.*

## Notes

- Uses VFX Graph meaning mobile & WebGL doesn't work.
- Works for URP & HDRP which can be upgraded via the **Tools → RFX → Welcome Screen → Setup** tab.
- Works for 2022, 2023, 6.0 and later which can be upgraded via the **Tools → RFX → Welcome Screen → Setup** tab.
