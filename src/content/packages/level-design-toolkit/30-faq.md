## Common questions

## Which render pipelines are supported?

Built-in, URP and HDRP. Follow the [Installation guide](./installation) to learn how to use the pack with your render pipeline. [For more compatibility information, refer to the Compatibility page](./compatibility).

## Which version of Unity are supported?

All versions. [For more compatibility information, refer to the Compatibility page](./compatibility).

## Which platforms are supported?

All platforms are supported. [For more compatibility information, refer to the Compatibility page](./compatibility).

## Can I use the tools in a commercial game?

Yes. The licence covers commercial projects, per the standard Unity Asset Store EULA.

## Can I use the tools in my 2D game?

Yes. Although the pack was made with 3D in mind, the tools can also be used in 2D.

## Can I use the tools in my 3D game?

Yes.
