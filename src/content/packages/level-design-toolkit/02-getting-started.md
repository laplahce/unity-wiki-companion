*This guide will help you get up and running with the pack.*

## Your first steps

### Checking out the tools

1. Open the **Level Design Toolkit → Demo → Demo** scene.
2. Select one of the tool GameObjects in the hierarchy.
3. Read how it works in the inspector and try it out.
4. To learn more about the different tools, make sure to check out the documentation for the different tools.
