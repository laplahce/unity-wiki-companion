**Level Design Toolkit** is a collection of level design tools for Unity that helps you create levels, design worlds or even prototyping.

## What's inside

- **Prefab Brush** that lets you place objects like you're painting.
- **Object Spawner** that lets you spawn objects in an area.
- **Billboard Painter** that lets you place billboards like you're painting (like painting vines, decals & more).
- **Object Placer** that lets you move objects fast using shortcuts.
- Customizable shortcuts.
