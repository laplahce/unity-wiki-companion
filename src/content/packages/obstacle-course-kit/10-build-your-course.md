*Learn how to easily build your own obstacle courses using grid snapping.*

## Enable grid snapping

1. Set tool handle rotation to **Global** in the scene view.
2. Enable **Grid Snapping** in the scene view.
3. Set **Grid Size** to **0.5**.

## Building a course

### Add a platform

1. Go to **Obstacle Course Kit → <RP> → Prefabs → Platforms → Platforms/\***.
2. Use the search bar in the project window to find the platform you are looking for, e.g. search for "floor" & select to search under the current folder.
3. Select a floor and drag it into your scene.

#### A tip:

It is important to learn the naming convention the pack uses to effectively create your courses.
The pattern is: `<type of floor (floor, corner, skew)>_<ramp type (none, ramp, ramp steep)>_<# of walls)>x<wall location>_<direction (none, L, R) **or** type of ramp>`.
For example, `Skew_Ramp_1x3_2_L` is a skew ramp that has 1 wall in the third location, second ramp type & facing left.

### Add an obstacle

1. Go to **Obstacle Course Kit → <RP> → Prefabs → Obstacles/\***.
2. Look through the category and find an obstacle you like.
3. Select it and drag it into your scene.
