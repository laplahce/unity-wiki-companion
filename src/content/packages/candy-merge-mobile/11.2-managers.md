*An overview of the manager systems.*

## Game Manager

Handles the overall game lifecycle. Only one instance is allowed at a time.

| Responsibility | What it does |
|---|---|
| Event System | Initializes and manages the Event System for input handling |
| Application Lifecycle | Cleans up resources when the application quits |
