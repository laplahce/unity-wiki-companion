*An overview of the menu system.*

## Classes

| Class | What it does |
|---|---|
| `MenuManager` | Singleton that plays the menu music on initialization |
| `CanvasUIManager` | Shows and hides the main and options menus |
| `OptionsUIManager` | Manages options menu animations and refreshes audio sliders |
| `MainUIManager` | Handles starting the game, exiting, and showing or hiding the main menu |
