*Learn to use the inputs settings.*

> Every setting has a tooltip you can read if you hover over it for a couple of seconds.

## How it works

1. Open **Candy Merge → _Config → Inputs**.
> The template has a custom way to handle inputs where each input is a scriptable object that can be referenced through a script. 
2. Open the **Controls** input action settings.
> Here you will see all the input settings. Notice how the inputs are separated into different schemes. These schemes will be automatically cycled through depending on the current state of the game. 
3. In the **Player** action scheme you will see the inputs that are matching the scriptable object in the settings folder. 
4. Each scriptable object is connected to its input via the `Reference` property.
5. To change a input, find the corresponding input in the **Controls** input action settings.
6. Expand it to reveal each binding.
7. You can either change an existing binding or add your own.
