*An overview of the UI component systems.*

## Components

| Class | What it does |
|---|---|
| `AudioSlider` | Slider that adjusts master or individual track volume and saves the setting |
| `SliderHandler` | Displays the current slider value in a text component |
| `ToggleHandler` | Syncs a toggle with saved data and updates it when the value changes |
