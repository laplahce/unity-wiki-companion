*An overview of the candy systems.*

## Candies

| Class | What it does |
|---|---|
| `CandyObject` | Defines a candy type, its appearance, value, and unlock status |
| `Candy` | Represents a candy in the world, handling its sprite, collider, and rigidbody |
| `CandyInWorld` | Handles merging and boundary checks between candies in the world |
| `CandyManager` | Creates and spawns candies |
| `CandyController` | Manages candy progression and unlocking |
| `CandySelector` | Selects and switches between candies based on weight |
| `CandiesObject` | Singleton that holds the root candy and provides access to all candy types |

## Spawner

| Class | What it does |
|---|---|
| `Spawner` | Manages candy spawning, switching, and drop input. Only one instance allowed at a time |
