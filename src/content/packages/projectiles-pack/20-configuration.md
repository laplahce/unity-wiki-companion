*This guide will help you change some fundemental settings in the pack.*

## Preferences

Open **Edit → Preferences → PSD2** to access the preferences.

### Theme

You can change the theming of the custom editor by simply changing the theme object in PSD2 preferences. You can find all the themes under **Projectiles Pack → PSD2 → Preferences → Themes** or create your own via **Create → PSD2 → Settings → Theming → Theme**.
