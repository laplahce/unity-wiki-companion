*Learn how to create effects using the custom editor.*

## Create your first effect

1. Create a new GameObject.
2. Add **Components → SPP2 → Projectile FX**.
3. You will then be prompted to select a place to store your materials. Select a folder that is inside your project (cannot be the root *Assets* folder).
4. Click **Edit FX**.
5. Navigate through the tabs and find one you want to add to.
6. Scroll down to **Particles** & add one. Here you can choose between a preset or an empty one.
