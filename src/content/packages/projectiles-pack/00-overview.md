**Projectiles Pack** is a collection of packs, each with 60 projectiles, 60 muzzles, 60 hit FXs for Unity. It also includes a powerful custom FX editor that lets you edit and create any projectile you like by simply adjusting a few sliders & choosing between over 250 custom textures.

## What's inside

- **60** projectiles.
- **60** muzzles & **60** hit FXs.
- **250+** textures.
- **Custom Editor** that is powerful, easy-to-use & lets you view changes in realtime.

### The Custom Editor

All the projectiles in the pack was created using the custom editor that ships with the pack. The pack is fully fledged out if you simply want to use the ready-made effects, but for those who want to edit or even create their own projectiles can use the custom editor. The editor separates the effect into components that you can change independently to build up a nice looking effect. For more information, [please refer to the Editing or Creating effect guide](./projectiles-pack/editing-an-effect).
