*Learn to use the camera settings.*

> Every setting has a tooltip you can read if you hover over it for a couple of seconds.

## How it works

1. Open **Candy Merge → _Config → Camera**.
> Some actions in the template causes the camera to shake (e.g. when merging). Each shake can be changed individually.
2. Select a camera shake and see the different properties.
3. Open **Candy Merge → _Config → Camera → Resources → Shake Config**.
4. Here you will see how we set which shake object that should be played on each action.
