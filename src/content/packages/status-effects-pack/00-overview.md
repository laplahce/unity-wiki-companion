**Status Effects Pack** is a pack with 60 status effects for Unity. It also includes a powerful custom FX editor that lets you edit and create any status effect you like by simply adjusting a few sliders & choosing between over 150 custom textures.

## What's inside

- **60** status effects.
- **150+** textures.
- **Custom Editor** that is powerful, easy-to-use & lets you view changes in realtime.

### The Custom Editor

All the effects in the pack was created using the custom editor that ships with the pack. The pack is fully fledged out if you simply want to use the ready-made effects, but for those who want to edit or even create their own status effects can use the custom editor. The editor separates the effect into components that you can change independently to build up a nice looking effect. For more information, [please refer to the Editing or Creating effect guide](./status-effects-pack/editing-an-effect).
